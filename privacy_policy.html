Политика конфиденциальности

FlorichDev · Редакция от 25.11.2026

Настоящая Политика конфиденциальности действует для мобильных приложений разработчика FlorichDev, распространяемых в магазине RuStore:

  • ФинРасчёт / ФинРасчёт PRO (ru.florichdev.creditcalc, ru.florichdev.creditcalc.pro)
  • ВольтМастер / ВольтМастер PRO (ru.florichdev.electrician, ru.florichdev.electrician.pro)
  • АвтоУчёт / АвтоУчёт PRO (ru.florichdev.autocost, ru.florichdev.autocost.pro)
  • РемСмета / РемСмета PRO (ru.florichdev.remontcalc, ru.florichdev.remontcalc.pro)
  • Мои Смены / Мои Смены PRO (ru.florichdev.shifts, ru.florichdev.shifts.pro)

1. Локальное хранение данных

Все расчёты, записи, графики, сметы, настройки и резервные копии хранятся исключительно локально на устройстве пользователя (в локальном хранилище приложения). Разработчик FlorichDev не имеет собственных серверов, не требует регистрации и не собирает, не хранит и не передаёт персональные или финансовые данные пользователей.

2. Отличия версий PRO и Free

  • PRO-версии (*.pro): работают полностью офлайн, не содержат рекламных и аналитических SDK и не запрашивают доступ в Интернет (INTERNET, ACCESS_NETWORK_STATE).
  • Бесплатные версии (Free): используют рекламный SDK Яндекс Мобильная Реклама (Yandex Mobile Ads) для показа баннеров и межстраничных объявлений.

3. Обработка данных рекламным партнёром (только Free-версии)

В бесплатных версиях приложений рекламный SDK ООО «ЯНДЕКС» (Yandex Mobile Ads) может автоматически обрабатывать технические данные устройства для показа и измерения эффективности рекламы: рекламный идентификатор устройства (AD_ID), IP-адрес, модель устройства, версию ОС, язык интерфейса и обезличенные события показа/кликов по объявлениям. Обработка регулируется Политикой конфиденциальности Яндекса: https://yandex.ru/legal/confidential/.

Пользователь может сбросить или ограничить использование рекламного идентификатора в настройках Android.

4. Разрешения устройства

  • POST_NOTIFICATIONS (ФинРасчёт, АвтоУчёт, Мои Смены): используется только для локальных напоминаний о платежах, ТО или сменах, которые настраивает сам пользователь.
  • INTERNET, ACCESS_NETWORK_STATE, AD_ID (только Free-версии): используются исключительно для загрузки рекламы Yandex Mobile Ads.

5. Экспорт и удаление данных

Пользователь в любой момент может экспортировать свои данные (CSV, JSON, PNG) стандартными средствами Android или полностью удалить их через очистку данных приложения / удаление приложения с устройства.

6. Контакты разработчика

По вопросам конфиденциальности вы можете связаться с разработчиком FlorichDev через контактный адрес, указанный на странице приложения в RuStore.

This Privacy Policy applies to mobile applications published by FlorichDev on RuStore:

  • FinCalc / FinCalc PRO (ru.florichdev.creditcalc, ru.florichdev.creditcalc.pro)
  • VoltMaster / VoltMaster PRO (ru.florichdev.electrician, ru.florichdev.electrician.pro)
  • AutoLog / AutoLog PRO (ru.florichdev.autocost, ru.florichdev.autocost.pro)
  • RenoPlan / RenoPlan PRO (ru.florichdev.remontcalc, ru.florichdev.remontcalc.pro)
  • ShiftPay / ShiftPay PRO (ru.florichdev.shifts, ru.florichdev.shifts.pro)

1. Local Data Storage

All calculations, records, schedules, estimates, preferences, and backups are stored exclusively on the user's device. FlorichDev operates no backend servers, requires no account registration, and does not collect, store, or transmit personal or financial user data.

2. PRO vs. Free Versions

  • PRO versions (*.pro): operate 100% offline, include zero advertising or analytics SDKs, and request no network permissions (INTERNET, ACCESS_NETWORK_STATE).
  • Free versions: integrate the Yandex Mobile Ads SDK to display banner and interstitial ads.

3. Advertising Partner Data (Free Versions Only)

In Free versions, the Yandex Mobile Ads SDK may automatically process technical device data to serve and measure ads, including the advertising ID (AD_ID), IP address, device model, OS version, interface language, and anonymized ad impression/click events. Processing is governed by the Yandex Privacy Policy: https://yandex.ru/legal/confidential/.

You can reset or limit advertising ID usage at any time in your Android system settings.

4. Device Permissions

  • POST_NOTIFICATIONS (FinCalc, AutoLog, ShiftPay): used solely for local on-device reminders configured by the user.
  • INTERNET, ACCESS_NETWORK_STATE, AD_ID (Free versions only): used exclusively to load ads via Yandex Mobile Ads.

5. Export and Deletion

Users may export their local data (CSV, JSON, PNG) via standard Android sharing or erase all stored data at any time by clearing app storage or uninstalling the application.

6. Developer Contact

For privacy inquiries, please contact FlorichDev via the developer contact email listed on the RuStore app page.
